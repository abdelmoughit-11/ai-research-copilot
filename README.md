# 🔬 AI Research Copilot

RAG application with automated evaluation.

## Tech Stack
- Groq (Llama 3.3 70B)
- ArXiv API
- FAISS + HuggingFace Embeddings
- PDF Analysis
- RAG Evaluation (Faithfulness, Relevancy, Context, Answer Score)
- Streamlit

## Setup
1. Clone the repo
2. pip install -r requirements.txt
3. Add GROQ_API_KEY in .env file
4. python -m streamlit run app/streamlit_app.py
